# Портфолио motion-дизайнера

Одностраничный сайт-портфолио с полноэкранной навигацией: экраны листаются колесом, свайпом и клавишами, текущий экран отражается в hash (`#skills`, `#project-2`, `#contacts`).

Стек: React 18, TypeScript, Vite, Less (CSS-модули), GSAP (Observer + анимация трека).

## Запуск

Нужен Node.js 18.18+.

```bash
npm install
npm run dev      # dev-сервер
npm run build    # проверка типов + сборка в dist/
npm run preview  # локальный просмотр сборки
npm run lint     # ESLint
```

`dist/` — статика, её можно выложить на любой статический хостинг.

## Где что лежит

| Путь | Что там |
| --- | --- |
| `src/data/content.ts` | Тексты, проекты, ссылки на видео, контакты, список экранов |
| `src/assets/media.ts` | Импорты картинок; сами файлы — в `src/assets/images/` (webp) |
| `src/fullpage/` | Полноэкранная навигация (`useFullpage`) и синхронизация высоты окна с `--app-height` |
| `src/screens/` | Экраны сайта, по одному компоненту на экран |
| `src/components/` | Общие компоненты: навигация, кнопка, карусель, модалки, QR |
| `src/styles/tokens.less` | Цвета, радиусы, брейкпоинты, общие миксины |
| `public/` | Шрифт Tilda Sans (woff2), favicon, картинка для превью ссылки |

## Контент

- **Видео** хранятся в Yandex Object Storage, в `content.ts` указываются прямые ссылки на mp4.
- **Новый проект** добавляется в `projects` в `content.ts`; картинки для карточки (крупная, две маленькие и мобильные кропы) подключаются в `media.ts`. Вместо `videoUrl` можно передать `gallery` — тогда «Смотреть» откроет лайтбокс.
- **Число шагов экрана** (`steps` в `screens`) должно совпадать с числом карточек на экране проектов.
